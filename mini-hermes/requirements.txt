# 本项目刻意**零第三方依赖** —— 不需要装任何东西。
#
# 这是设计选择，不是疏忽：
#   · 手搓 urllib 发 HTTP，你才能看清 API payload 的真实长相
#     （tools 字段、tool_choice、消息数组到底长什么样）
#   · 套个 openai SDK 就把这一层糊住了 —— 而这个项目的目的就是看清它
#   · 少一层依赖 = 少一个"装不上"的理由，别人 clone 下来直接能跑
#
# 所以这里故意不写任何包名。跑之前只需要：
#   python3 -V        # 需要 3.9 或更高（3.9 已实测通过）
#
# 如果哪天某一章真的引入了第三方库，就在这里加上，并且**改 README 的打包说明**。
# 目前规划中的章节都不会需要：
#   SQLite + FTS5 会话存储 → sqlite3 是标准库
#   流式输出              → urllib 能读 SSE 流
#   网页抓取工具           → urllib + html.parser
